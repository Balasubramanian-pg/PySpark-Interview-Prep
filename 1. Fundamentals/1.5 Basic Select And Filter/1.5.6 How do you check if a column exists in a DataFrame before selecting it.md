# 1.5.6 How do you check if a column exists in a DataFrame before selecting it?

The standard way is to inspect `df.columns`, which returns a list of column names as strings. Check membership with Python’s `in` operator, or use `df.schema.fieldNames()` for the same list. For case-insensitive checks, normalize both sides with `.lower()`.
- **Use `df.columns`**: Returns a list of column names. Check with `"amount" in df.columns`.
- **Use `df.schema.fieldNames()`**: Equivalent to `df.columns`, returning a list of field names from the schema.
- **Case sensitivity**: Column names are case-sensitive by default. Use `col.lower() in [c.lower() for c in df.columns]` for case-insensitive matching.
- **Check before selecting**: Guard the `select()` call with an `if` statement or build the column list conditionally.
- **Use `df.schema` for type checks**: Inspect `df.schema["amount"].dataType` if you also need to verify the column type.
- **Do not rely on exceptions**: Catching the error from `select()` works but is slower and less readable than checking upfront.
> [!IMPORTANT]
> `df.columns` and `df.schema.fieldNames()` are metadata reads. They do not scan data or trigger a job, so checking column existence is cheap.
> [!WARNING]
> Column names are case-sensitive by default. `"Amount" in df.columns` returns `False` if the column is named `"amount"`. Normalize case if your pipeline mixes naming conventions.
> [!NOTE]
> If you need to select only the columns that exist from a candidate list, use a list comprehension: `[c for c in candidates if c in df.columns]`, then pass it to `select()`.
### Clear Definitions
- **`df.columns`**: A property that returns a list of column names as strings.
- **`df.schema.fieldNames()`**: A method on the schema that returns the same list of field names.
- **`df.schema`**: The `StructType` describing column names and types.
- **Case-sensitive**: Matching that distinguishes uppercase and lowercase letters.
- **Metadata read**: An operation that reads only schema information, not data.
### Worked Example
Assume `df` has columns `id`, `country`, and `amount`.
```python
# Simple existence check
if "amount" in df.columns:
    result = df.select("id", "amount")
else:
    result = df.select("id")
# Select only the columns that exist from a candidate list
candidates = ["id", "country", "status"]
existing = [c for c in candidates if c in df.columns]
result = df.select(*existing)
# Case-insensitive check
lower_cols = [c.lower() for c in df.columns]
if "amount" in lower_cols:
    print("amount column exists")
```
Step by step:
1. `df.columns` returns `["id", "country", "amount"]`.
2. `"amount" in df.columns` evaluates to `True`, so the first branch runs.
3. The candidate list `["id", "country", "status"]` is filtered to `["id", "country"]` because `status` does not exist.
4. `df.select(*existing)` selects only the columns that are present.
5. The case-insensitive check normalizes all names to lowercase before comparing.
6. No job runs during any of these checks because they read only metadata.
In short: check `"col" in df.columns` before selecting. It is a cheap metadata read, avoids runtime errors, and lets you build column lists conditionally. Normalize case if your column naming is inconsistent.
