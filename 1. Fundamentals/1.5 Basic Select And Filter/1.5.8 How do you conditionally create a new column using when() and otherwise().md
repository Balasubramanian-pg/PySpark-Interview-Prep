# 1.5.8 How do you conditionally create a new column using when() and otherwise()?

### 1.5.8 Conditionally create a new column using when() and otherwise()
Use `F.when(condition, value).otherwise(default)` inside `withColumn()` or `select()`. `when()` evaluates a condition for each row and returns the value if the condition is true. `otherwise()` supplies the value when none of the `when()` conditions match. You can chain multiple `when()` calls to express if/elif/else logic.

- **Basic form**: `F.when(cond, result).otherwise(default)` returns a Column expression.
- **Chain multiple conditions**: Add more `.when(cond2, result2)` calls before `.otherwise(default)` to create if/elif/else logic.
- **Always add `otherwise()`**: Without it, rows that match no condition get `null`, which may not be what you want.
- **Use inside `withColumn()`**: `df.withColumn("new_col", F.when(...).otherwise(...))` adds or replaces a column.
- **Use inside `select()`**: `df.select("id", F.when(...).otherwise(...).alias("label"))` controls output columns precisely.
- **Conditions are Column expressions**: Use `F.col("amount") > 100`, `F.col("status") == "active"`, or null checks with `.isNull()`.
- **Null handling**: A `when()` condition that evaluates to null is treated as false, so the row falls through to the next condition or `otherwise()`.
- **Type consistency**: All branches should return compatible types. Mixing strings and numbers in branches can cause cast errors.
- **It is a lazy transformation**: No job runs until an action such as `show()` or `count()` is called.

> [!IMPORTANT]
> `when()` without `otherwise()` returns null for unmatched rows. Always add `otherwise()` unless null is the intended default.

> [!WARNING]
> All branches of a `when()` chain should return the same or compatible data types. Mixing types such as string and integer can cause unexpected casts or runtime errors.

> [!NOTE]
> Chained `when()` calls are evaluated in order. The first matching condition wins, so put the most specific conditions first.

### Clear Definitions

- **`when(condition, value)`**: A function that returns a Column expression evaluating to `value` when `condition` is true.
- **`otherwise(value)`**: A method that supplies the default value when no `when()` condition matches.
- **`withColumn(name, expr)`**: A transformation that adds or replaces a column using an expression.
- **`select()`**: A transformation that returns a new DataFrame with the specified columns and expressions.
- **Column expression**: A lazy expression representing a computation over one or more columns.
- **Null fallthrough**: The behavior where a null condition is treated as false in `when()`.

### Worked Example

Assume `df` has columns `id`, `amount`, and `status`.

```python
from pyspark.sql import functions as F

result = df.withColumn(
    "category",
    F.when(F.col("amount") > 1000, "high")
     .when(F.col("amount") > 100, "medium")
     .otherwise("low")
)

result.show()
```

Step by step:
1. `F.col("amount") > 1000` is checked first. Rows above 1000 get `"high"`.
2. Rows that fail the first condition are checked against `F.col("amount") > 100`. Matching rows get `"medium"`.
3. All remaining rows fall through to `otherwise("low")`.
4. `withColumn("category", ...)` adds the new column to the DataFrame.
5. The original `df` is unchanged because DataFrames are immutable.
6. No job runs until `result.show()` is called.
7. Catalyst evaluates the conditions row by row on executors.

**Using `select()` instead**

```python
result = df.select(
    "id",
    "amount",
    F.when(F.col("status") == "active", 1).otherwise(0).alias("is_active")
)
```

Step by step:
1. `F.col("status") == "active"` is true for active rows.
2. Active rows get `1`; all others get `0`.
3. `.alias("is_active")` names the new column.
4. `select()` returns only `id`, `amount`, and `is_active`.
5. Rows with null `status` fall through to `otherwise(0)` because null comparisons are treated as false in `when()`.

In short: use `F.when(condition, value).otherwise(default)` inside `withColumn()` or `select()` to create conditional columns. Chain multiple `when()` calls for if/elif/else logic, always add `otherwise()` to avoid unintended nulls, and keep branch types consistent.
