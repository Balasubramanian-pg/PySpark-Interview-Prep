# 1.5.4 How do you rename a column in a PySpark DataFrame?

PySpark offers several ways to rename columns. The most common are `withColumnRenamed()`, `select()` with `alias()`, and `toDF()` for renaming multiple columns at once.

- **`withColumnRenamed()` for one column**: `df.withColumnRenamed("old", "new")` returns a new DataFrame with that single column renamed.
- **Chain `withColumnRenamed()` for several columns**: Call it repeatedly, or use `functools.reduce` to rename many columns programmatically.
- **`select()` with `alias()` for fine control**: `df.select(F.col("old").alias("new"), "*")` renames while also letting you reorder or compute expressions.
- **`toDF()` for bulk renaming**: `df.toDF("col1", "col2", ...)` replaces all column names at once. The number of names must match the number of columns exactly.
- **All approaches are lazy**: They return a new DataFrame and do not trigger a job until an action is called.
- **Original DataFrame is unchanged**: Spark DataFrames are immutable, so renaming always returns a new DataFrame.
- **Watch for duplicate names**: `withColumnRenamed()` renames all columns with the matching name. `toDF()` can create duplicates if you pass repeated names.

> [!IMPORTANT]
> `withColumnRenamed()` is the simplest choice for one or a few columns. Use `toDF()` when you want to replace every column name at once, and `select().alias()` when renaming is combined with other column transformations.

> [!WARNING]
> `toDF()` requires exactly as many names as there are columns. If the counts do not match, Spark raises an error. It also renames by position, so column order matters.

> [!NOTE]
> In PySpark, `withColumnRenamed()` does not raise an error if the old name does not exist. It silently returns the DataFrame unchanged. Always verify the result with `df.columns` or `df.printSchema()`.

### Clear Definitions

- **`withColumnRenamed(old, new)`**: A DataFrame method that returns a new DataFrame with one column renamed.
- **`alias()`**: A Column method that assigns a new name to a column expression.
- **`toDF(*names)`**: A DataFrame method that renames all columns by position.
- **Immutable**: The property that a DataFrame cannot be changed in place; every transformation returns a new DataFrame.
- **Transformation**: A lazy operation that returns a new DataFrame without triggering execution.

### Worked Example

Assume `df` has columns `id`, `country`, and `amount`.

**Rename one column**
```python
renamed = df.withColumnRenamed("amount", "total_amount")
```

**Rename several columns with chaining**
```python
renamed = df.withColumnRenamed("amount", "total_amount") \
            .withColumnRenamed("country", "country_code")
```

**Rename several columns with reduce**
```python
from functools import reduce

mapping = {"amount": "total_amount", "country": "country_code"}
renamed = reduce(
    lambda d, kv: d.withColumnRenamed(kv[0], kv[1]),
    mapping.items(),
    df
)
```

**Rename with select and alias**
```python
from pyspark.sql import functions as F

renamed = df.select(
    F.col("id"),
    F.col("country").alias("country_code"),
    F.col("amount").alias("total_amount")
)
```

**Rename all columns with toDF**
```python
renamed = df.toDF("id", "country_code", "total_amount")
```

Step by step:
1. `df` has columns `id`, `country`, and `amount`.
2. `withColumnRenamed("amount", "total_amount")` returns a new DataFrame with `id`, `country`, and `total_amount`.
3. Chaining or `reduce` renames multiple columns in one pipeline.
4. `select(...alias(...))` gives the same result and also lets you reorder or compute columns in the same call.
5. `toDF(...)` renames all columns by position, so the order of the names must match the column order.
6. All results are new DataFrames. The original `df` still has its original column names.
7. Nothing runs until an action such as `renamed.show()` or `renamed.printSchema()` is called.

In short: use `withColumnRenamed()` for one or a few columns, `reduce` for programmatic bulk renaming, `select().alias()` when renaming is combined with other transformations, and `toDF()` when replacing every column name at once.
