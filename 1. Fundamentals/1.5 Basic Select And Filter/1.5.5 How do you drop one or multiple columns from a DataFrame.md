# 1.5.5 How do you drop one or multiple columns from a DataFrame?

Use `df.drop("col")` to remove one column or `df.drop("col1", "col2", ...)` to remove several columns. You can also pass a list with `df.drop(*["col1", "col2"])`. The method returns a new DataFrame and leaves the original unchanged.
- **Drop one column**: `df.drop("amount")` returns a new DataFrame without `amount`.
- **Drop multiple columns**: `df.drop("country", "status")` removes both columns in one call.
- **Drop from a list**: `df.drop(*columns_to_drop)` unpacks a Python list into separate arguments.
- **Drop by expression**: `df.drop(df.amount)` also works when you pass a Column object.
- **Case sensitivity**: Column names are case-sensitive by default. Use the exact name from `df.columns`.
- **No error if missing**: If the column does not exist, `drop()` silently ignores it and returns the DataFrame unchanged.
- **Lazy transformation**: `drop()` does not trigger a job. Execution starts only when an action such as `show()` or `count()` is called.
- **Original is unchanged**: DataFrames are immutable, so `drop()` always returns a new DataFrame.
> [!IMPORTANT]
> `drop()` removes columns, not rows. To remove rows, use `filter()` or `where()`. To drop rows with nulls, use `df.na.drop()`.
> [!WARNING]
> `drop()` does not raise an error when a column name is missing. A typo silently leaves the column in place. Check `df.columns` before and after if the schema matters.
> [!NOTE]
> You can also drop columns by selecting the ones you want to keep: `df.select("id", "amount")`. Use `drop()` when listing the columns to remove is shorter than listing the columns to keep.
### Clear Definitions
- **`drop()`**: A DataFrame transformation that returns a new DataFrame without the specified columns.
- **Column object**: A reference to a column, such as `df.amount` or `F.col("amount")`, which can be passed to `drop()`.
- **Immutable**: The property that a DataFrame cannot be changed in place; transformations return new DataFrames.
- **Transformation**: A lazy operation that returns a new DataFrame without triggering execution.
- **Action**: An operation that triggers computation, such as `show()` or `count()`.
### Worked Example
Assume `df` has columns `id`, `country`, `amount`, and `status`.
```python
# Drop one column
no_amount = df.drop("amount")
# Drop multiple columns
no_country_status = df.drop("country", "status")
# Drop columns from a list
columns_to_drop = ["country", "status"]
no_country_status = df.drop(*columns_to_drop)
# Drop by Column object
no_amount = df.drop(df.amount)
# Drop columns with nulls in any row
no_nulls = df.na.drop()
```
Step by step:
1. `df` has columns `id`, `country`, `amount`, and `status`.
2. `df.drop("amount")` returns a new DataFrame with `id`, `country`, and `status`.
3. `df.drop("country", "status")` returns a new DataFrame with only `id` and `amount`.
4. `df.drop(*columns_to_drop)` does the same as step 3 using a list.
5. `df.drop(df.amount)` also removes `amount` by passing the Column object.
6. `df.na.drop()` removes rows with nulls, not columns. It is a different operation.
7. The original `df` still has all four columns because DataFrames are immutable.
8. No job runs until an action such as `no_amount.show()` is called.
In short: use `df.drop("col1", "col2")` or `df.drop(*list_of_cols)` to remove columns. It is lazy, immutable, and silently ignores missing names. Use `select()` when listing the columns to keep is simpler.
