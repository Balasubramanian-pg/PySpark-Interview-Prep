# 1.4.1 How do you read a CSV file into a DataFrame with headers and inferred schema?

### 1.4.1 Read a CSV file into a DataFrame with headers and inferred schema
Use `spark.read.csv()` with `header=True` and `inferSchema=True`. `header=True` treats the first row as column names. `inferSchema=True` makes Spark scan the data and infer column types such as integer, double, string, and date-like values.
```python
df = spark.read.csv(
    "data/sales.csv",
    header=True,
    inferSchema=True
)
df.printSchema()
df.show(5)
```
- **`header=True`**: Uses the first CSV row as column names instead of `_c0`, `_c1`, and so on.
- **`inferSchema=True`**: Scans the file to guess column data types instead of reading every column as `string`.
- **Without `inferSchema`**: All columns are strings by default, which is safe but often inconvenient for numeric work.
- **With `inferSchema`**: Spark performs an extra pass over the data, which costs time on large files.
- **Production advice**: For large or repeated pipelines, define an explicit schema instead of inferring it.
> [!IMPORTANT]
> `header=True` controls column names. `inferSchema=True` controls column types. They solve different problems and are often used together for quick exploration.
> [!NOTE]
> `inferSchema=True` adds a data-scanning pass. For large files, an explicit `StructType` schema is faster and more reliable because it avoids inference and type surprises.
> [!WARNING]
> Schema inference can misclassify columns, for example a numeric-looking ID may become an integer and lose leading zeros. Specify the schema when exact types matter.
### Clear Definitions
- **DataFrame**: A distributed table with named columns and a schema.
- **Header**: The first row of a CSV file that contains column names.
- **Schema inference**: Spark scanning data to guess column data types.
- **Explicit schema**: A user-defined `StructType` that declares column names and types exactly.
- **`spark.read.csv()`**: The DataFrameReader method for reading CSV files.
### Worked Example
CSV file `sales.csv`:
```text
order_id,country,amount
1,IN,120.50
2,US,80.00
3,IN,200.00
```
Code:
```python
df = spark.read.csv("sales.csv", header=True, inferSchema=True)
df.printSchema()
df.show()
```
Step by step:
1. Spark opens `sales.csv` and reads the first row as column names: `order_id`, `country`, `amount`.
2. Because `inferSchema=True`, Spark scans the values and infers `order_id` as integer, `country` as string, and `amount` as double.
3. `printSchema()` shows the inferred column names and types.
4. `show()` displays the rows as a table.
5. If you omitted `inferSchema=True`, all three columns would be strings.
6. If you provided an explicit schema, Spark would skip inference and read the file using your declared types.
In short: use `spark.read.csv(path, header=True, inferSchema=True)` for quick CSV loading with column names and guessed types. Use an explicit schema for large production files where speed and type accuracy matter.
