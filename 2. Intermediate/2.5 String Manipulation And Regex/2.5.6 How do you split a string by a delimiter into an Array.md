# 2.5.6 How do you split a string by a delimiter into an Array?

## 2.5.6 How do you split a string by a delimiter into an Array?

Use `split(str, pattern)`. It returns an array of strings. The delimiter is a Java regex, not a literal string. Use `regexp_split_to_array` in SQL when available, or `split` in the DataFrame API.

```mermaid
graph TD
    A[String column] --> B[split col, pattern]
    B --> C{Delimiter is regex special char?}
    C -->|Yes| D[Escape it. Use "\\|" or "[.]"]
    C -->|No| E[Use literal]
    D --> F[Array of strings]
    E --> F
    F --> G{Need one element?}
    G -->|Yes| H[Index the array. 0-based]
    G -->|No| I[Use explode to get rows]
    G -->|No| J[Use size, element_at, or array_contains]
```

### Core function

| API | Form | Note |
|---|---|---|
| PySpark | `split(col("s"), pattern)` | Pattern is Java regex |
| Scala | `split(col("s"), pattern)` | Pattern is Java regex |
| SQL | `split(s, pattern)` | Pattern is Java regex |
| Optional limit | `split(col("s"), pattern, limit)` | Spark 3.0+, limit < 0 means no limit |
| Optional limit | `split(col("s"), pattern, limit)` | Limit > 0 caps array size |

| Property | Behavior |
|---|---|
| Return type | `ArrayType(StringType)` |
| Element type | Always string. Cast after splitting if numbers are needed |
| Index base | 0-based when you access an element |
| Null input | Returns `null` |
| Empty input | Returns `[""]` (one element, empty string) |
| No delimiter found | Returns `[original_string]` |
| Consecutive delimiters | Produces empty string elements |
| Trailing delimiter | Produces a trailing empty string element (with limit < 0) |
| Leading delimiter | Produces a leading empty string element |

### Basic examples

PySpark:

```python
from pyspark.sql.functions import col, split

df = (
    df
    .withColumn("parts", split(col("csv"), ","))
    .withColumn("first", split(col("csv"), ",")[0])
    .withColumn("last",  split(col("csv"), ",")[-1])
)
```

Scala:

```scala
import org.apache.spark.sql.functions._

val out = df
  .withColumn("parts", split(col("csv"), ","))
  .withColumn("first", split(col("csv"), ",")(0))
```

SQL:

```sql
SELECT
  split(csv, ',')         AS parts,
  split(csv, ',')[0]      AS first
FROM t;
```

### Delimiter behavior table

| Input | Pattern | Result |
|---|---|---|
| `a,b,c` | `,` | `["a","b","c"]` |
| `a,,c` | `,` | `["a","","c"]` |
| `,a,b` | `,` | `["","a","b"]` |
| `a,b,` | `,` | `["a","b",""]` with default limit < 0 |
| `a\|b\|c` | `\\\|` | `["a","b","c"]` |
| `a.b.c` | `\\.` | `["a","b","c"]` |
| `a  b  c` | `\\s+` | `["a","b","c"]` |
| `a, b, c` | `,\\s*` | `["a","b","c"]` |
| `no_delim` | `,` | `["no_delim"]` |
| `""` | `,` | `[""]` |
| `null` | `,` | `null` |

### Regex special characters

The delimiter is a Java regex. Characters such as `.`, `|`, `\`, `+`, `*`, `?`, `(`, `)`, `[`, `]`, `{`, `}`, `^`, `$` have special meaning. Escape them.

| Literal delimiter | Regex pattern | Python raw string |
|---|---|---|
| `.` | `\.` | `r"\."` |
| `\|` | `\|` | `r"\|"` |
| `\` | `\\` | `r"\\"` |
| `+` | `\+` | `r"\+"` |
| `*` | `\*` | `r"\*"` |
| `(` `)` | `\(` `\)` | `r"\("` `r"\)"` |
| `[` `]` | `\[` `\]` | `r"\["` |
| `{` `}` | `\{` `\}` | `r"\{"` |

For a multi-character delimiter that contains regex specials, wrap in a character class or escape each character. Using `Pattern.quote` style is not available in Spark SQL, so escape manually.

### Limit argument

`split(str, pattern, limit)` controls array size.

| Limit | Behavior |
|---|---|
| `limit < 0` | No limit. Default. All parts kept, trailing empties kept |
| `limit == 0` | No limit but trailing empties dropped |
| `limit > 0` | At most `limit` elements. Last element contains the rest |

```python
from pyspark.sql.functions import col, split

df.withColumn("parts", split(col("s"), ",", 3))
```

| Input | Limit | Result |
|---|---|---|
| `a,b,c,d,e` | 3 | `["a","b","c,d,e"]` |
| `a,b,c,d,e` | 0 | `["a","b","c","d","e"]` |
| `a,b,c,,` | 0 | `["a","b","c"]` |
| `a,b,c,,` | -1 | `["a","b","c","",""]` |

### Accessing elements

| Goal | PySpark | SQL |
|---|---|---|
| First element | `split(col("s"), ",")[0]` | `split(s, ',')[0]` |
| Second element | `split(col("s"), ",")[1]` | `split(s, ',')[1]` |
| Last element | `element_at(split(col("s"), ","), -1)` | `element_at(split(s, ','), -1)` |
| Safe access with default | `split(col("s"), ",")[1]` returns `null` when out of range | Same |
| Size of array | `size(split(col("s"), ","))` | `size(split(s, ','))` |
| Test containment | `array_contains(split(col("s"), ","), lit("target"))` | `array_contains(split(s, ','), 'target')` |

Out-of-range index returns `null`, not an error. This is safe but silent.

### Explode to rows

`explode` turns one row with an array into many rows, one per element. `posexplode` also gives the index.

```python
from pyspark.sql.functions import col, split, explode, posexplode

df.select("id", explode(split(col("csv"), ",")).alias("part"))
df.select("id", posexplode(split(col("csv"), ",")).alias("pos", "part"))
```

| Function | Output |
|---|---|
| `explode` | One row per element |
| `posexplode` | One row per element plus its index |
| `explode_outer` | Same as `explode` but keeps rows with null or empty arrays |
| `posexplode_outer` | Same as `posexplode` but keeps empty arrays |

`explode` drops rows with `null` or empty array input. Use `explode_outer` to keep them.

### Casting array elements

`split` always returns strings. Cast the array with `cast("array<int>")` or cast individual elements.

```python
from pyspark.sql.functions import col, split

df = (
    df
    .withColumn("int_parts", split(col("csv"), ",").cast("array<int>"))
    .withColumn("first_int", split(col("csv"), ",")[0].cast("int"))
)
```

Invalid elements become `null` in non-ANSI mode and throw in ANSI mode. Filter or validate before casting if the input is untrusted.

### Null and empty handling

| Input | split result |
|---|---|
| `null` | `null` |
| `""` | `[""]` (one empty string) |
| `,` | `["",""]` (two empty strings) |
| `,,` | `["","",""]` (three empty strings) |

`size(split(...))` on `null` returns `-1`. On `[""]` returns `1`. This is a common source of wrong branch logic.

```python
from pyspark.sql.functions import col, split, size, when

df.withColumn(
    "n_parts",
    when(col("s").isNull(), 0).otherwise(size(split(col("s"), ",")))
)
```

### Common pitfalls

| Pitfall | Effect | Fix |
|---|---|---|
| Using `.` as delimiter without escaping | Splits on every char | Use `r"\."` |
| Using `\|` without escaping | Splits on every char | Use `r"\|"` |
| Forgetting Python raw string | `\d` becomes `d` or raises | Use `r"\d"` |
| SQL string escaping | `\\d` needed in some contexts | Use `[0-9]` to avoid backslashes |
| Assuming trailing empty is kept | With `limit == 0` it is dropped | Use `limit < 0` to keep it |
| Indexing beyond array size | Returns `null`, silent | Check `size` first if needed |
| Using `explode` on null | Row is dropped | Use `explode_outer` |
| Splitting before filtering | Extra work on rows that will be dropped | Filter first |
| Splitting repeatedly | Costly regex per call | Split once and reuse the column |
| Casting the array directly | Invalid elements become `null` | Validate with `rlike` or `regexp_extract` first |

### Performance notes

- `split` is native and codegen friendly. It uses Java regex.
- Simple delimiters such as `,` are cheap. Complex patterns and backtracking are expensive.
- Reuse the array column. Do not call `split` multiple times on the same input.
- `explode` multiplies row count. It can shuffle if used before a join or group by. Apply it late and only on the columns needed.
- Casting an array with `cast("array<int>")` is native and faster than a UDF.
- Avoid Python UDFs for splitting. Use native `split`.

### End to end example

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, split, explode, size, element_at

spark = SparkSession.builder.getOrCreate()

df = spark.createDataFrame(
    [("a,b,c",), ("a,,c",), ("only",), ("",), (None,)],
    ["csv"]
)

out = (
    df
    .withColumn("parts", split(col("csv"), ","))
    .withColumn("n", size(split(col("csv"), ",")))
    .withColumn("first", split(col("csv"), ",")[0])
    .withColumn("last", element_at(split(col("csv"), ","), -1))
)

out.show(truncate=False)
out.select("csv", explode(split(col("csv"), ",")).alias("part")).show()
```

| csv | parts | n | first | last |
|---|---|---|---|---|
| `a,b,c` | `["a","b","c"]` | 3 | `a` | `c` |
| `a,,c` | `["a","","c"]` | 3 | `a` | `c` |
| `only` | `["only"]` | 1 | `only` | `only` |
| `""` | `[""]` | 1 | empty | empty |
| null | null | -1 | null | null |

The `n` column shows the `-1` case for null input. Handle it explicitly when `n` drives downstream logic.
