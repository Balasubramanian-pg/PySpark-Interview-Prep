# 2.1.1 List the different types of joins available in PySpark.

Here is a complete, working PySpark script that demonstrates the syntax and exact output for every join type. 

To clearly see the differences, we will use two DataFrames:
* **`emp_df` (Employees)**: Contains employees. Notice that "Charlie" belongs to department 30, which *does not exist* in the department table.
* **`dept_df` (Departments)**: Contains departments. Notice that "Marketing" is department 40, which *has no employees*.

### 0. Setup: Creating the SparkSession and DataFrames

```python
from pyspark.sql import SparkSession

# Initialize SparkSession
spark = SparkSession.builder.appName("AllJoinTypes").getOrCreate()

# Create Employee DataFrame (Left Table)
emp_data = [
    (1, "Alice", 10),
    (2, "Bob", 20),
    (3, "Charlie", 30), # No matching department
    (4, "Dave", 10)
]
emp_df = spark.createDataFrame(emp_data, ["emp_id", "emp_name", "dept_id"])

# Create Department DataFrame (Right Table)
dept_data = [
    (10, "HR"),
    (20, "Engineering"),
    (40, "Marketing")    # No matching employees
]
dept_df = spark.createDataFrame(dept_data, ["dept_id", "dept_name"])

print("--- Employee DataFrame ---")
emp_df.show()
print("--- Department DataFrame ---")
dept_df.show()
```

### 1. Inner Join
**Syntax:** `df1.join(df2, on="key", how="inner")`
**Rule:** Keeps only rows where the key exists in BOTH DataFrames. Charlie and Marketing are dropped.

```python
inner_join_df = emp_df.join(dept_df, on="dept_id", how="inner")
inner_join_df.show()

# Output:
# +-------+------+--------+-----------+
# |dept_id|emp_id|emp_name|  dept_name|
# +-------+------+--------+-----------+
# |     10|     1|   Alice|         HR|
# |     10|     4|    Dave|         HR|
# |     20|     2|     Bob|Engineering|
# +-------+------+--------+-----------+
```

### 2. Left (Outer) Join
**Syntax:** `df1.join(df2, on="key", how="left")`
**Rule:** Keeps EVERYTHING from the Left (`emp_df`). If there is no match in the Right (`dept_df`), it fills the right-side columns with `null`.

```python
left_join_df = emp_df.join(dept_df, on="dept_id", how="left")
left_join_df.show()

# Output:
# +-------+------+--------+-----------+
# |dept_id|emp_id|emp_name|  dept_name|
# +-------+------+--------+-----------+
# |     10|     1|   Alice|         HR|
# |     20|     2|     Bob|Engineering|
# |     30|     3| Charlie|       null| <-- Kept from Left, null on Right
# |     10|     4|    Dave|         HR|
# +-------+------+--------+-----------+
```

### 3. Right (Outer) Join
**Syntax:** `df1.join(df2, on="key", how="right")`
**Rule:** Keeps EVERYTHING from the Right (`dept_df`). If there is no match in the Left (`emp_df`), it fills the left-side columns with `null`.

```python
right_join_df = emp_df.join(dept_df, on="dept_id", how="right")
right_join_df.show()

# Output:
# +-------+------+--------+-----------+
# |dept_id|emp_id|emp_name|  dept_name|
# +-------+------+--------+-----------+
# |     10|     1|   Alice|         HR|
# |     10|     4|    Dave|         HR|
# |     20|     2|     Bob|Engineering|
# |     40|  null|    null|  Marketing| <-- Kept from Right, null on Left
# +-------+------+--------+-----------+
```

### 4. Full (Outer) Join
**Syntax:** `df1.join(df2, on="key", how="full")`
**Rule:** Keeps EVERYTHING from BOTH DataFrames. Missing matches on either side are filled with `null`.

```python
full_join_df = emp_df.join(dept_df, on="dept_id", how="full")
full_join_df.show()

# Output:
# +-------+------+--------+-----------+
# |dept_id|emp_id|emp_name|  dept_name|
# +-------+------+--------+-----------+
# |     10|     1|   Alice|         HR|
# |     10|     4|    Dave|         HR|
# |     20|     2|     Bob|Engineering|
# |     30|     3| Charlie|       null| <-- Missing match on Right
# |     40|  null|    null|  Marketing| <-- Missing match on Left
# +-------+------+--------+-----------+
```

### 5. Left Semi Join
**Syntax:** `df1.join(df2, on="key", how="semi")`
**Rule:** Returns ONLY columns from the Left DataFrame where a match exists in the Right DataFrame. (Acts like `SELECT * FROM emp WHERE dept_id IN (SELECT dept_id FROM dept)`).

```python
semi_join_df = emp_df.join(dept_df, on="dept_id", how="semi")
semi_join_df.show()

# Output:
# +-------+------+--------+
# |dept_id|emp_id|emp_name| <-- Notice: No dept_name column!
# +-------+------+--------+
# |     10|     1|   Alice|
# |     10|     4|    Dave|
# |     20|     2|     Bob|
# +-------+------+--------+
```

### 6. Left Anti Join
**Syntax:** `df1.join(df2, on="key", how="anti")`
**Rule:** Returns ONLY rows from the Left DataFrame that DO NOT have a match in the Right DataFrame. Returns ONLY columns from the Left. (Great for finding orphans/anomalies).

```python
anti_join_df = emp_df.join(dept_df, on="dept_id", how="anti")
anti_join_df.show()

# Output:
# +-------+------+--------+
# |dept_id|emp_id|emp_name|
# +-------+------+--------+
# |     30|     3| Charlie| <-- The only employee with an invalid department
# +-------+------+--------+
```

### 7. Cross Join
**Syntax:** `df1.crossJoin(df2)` OR `df1.join(df2, how="cross")`
**Rule:** Returns the Cartesian product (every row in Left matched with every row in Right). No `on="key"` is needed. 4 employees × 3 departments = 12 total rows.

```python
# Note: Since there is no "on" parameter, both DataFrames keep their own dept_id column
cross_join_df = emp_df.crossJoin(dept_df)
cross_join_df.show()

# Output:
# +------+--------+-------+-------+-----------+
# |emp_id|emp_name|dept_id|dept_id|  dept_name|
# +------+--------+-------+-------+-----------+
# |     1|   Alice|     10|     10|         HR|
# |     1|   Alice|     10|     20|Engineering|
# |     1|   Alice|     10|     40|  Marketing|
# |     2|     Bob|     20|     10|         HR|
# |     2|     Bob|     20|     20|Engineering|
# |     2|     Bob|     20|     40|  Marketing|
# |     3| Charlie|     30|     10|         HR|
# |     3| Charlie|     30|     20|Engineering|
# |     3| Charlie|     30|     40|  Marketing|
# |     4|    Dave|     10|     10|         HR|
# |     4|    Dave|     10|     20|Engineering|
# |     4|    Dave|     10|     40|  Marketing|
# +------+--------+-------+-------+-----------+
```
