# Security Policy

## Supported Versions

This repository is an educational resource for PySpark interview preparation. Security updates are applied to the current version of the repository on a best-effort basis.

| Version | Supported |
| ------- | --------- |
| Latest `main` | Yes |
| Older commits and snapshots | No |

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it responsibly.

- **Reporting channel:** Open a GitHub issue for non-sensitive security concerns. For vulnerabilities involving exposed credentials, secrets, or other sensitive information, do not disclose details in a public issue. Use GitHub's private vulnerability reporting feature if enabled for this repository.
- **Acknowledgment:** Reports will be reviewed on a best-effort basis. No fixed response time is guaranteed.
- **Assessment:** Reports will be evaluated to determine their validity, severity, and potential impact.
- **Resolution:** Accepted reports will be addressed through an appropriate fix or repository update. Where applicable, the fix will be documented in the commit history or release notes.
- **Declined reports:** If a report is not considered a valid security vulnerability, an explanation will be provided where reasonably possible.
- **Disclosure:** Please avoid publicly disclosing vulnerability details until the issue has been assessed and an appropriate resolution has been made.

## Scope

This policy covers security issues directly related to the contents and configuration of this repository, including accidentally committed credentials, exposed secrets, unsafe scripts, and vulnerable dependencies introduced by the project.

This repository is intended for educational purposes. Users should independently validate code and follow appropriate security practices before using any examples in production environments.
