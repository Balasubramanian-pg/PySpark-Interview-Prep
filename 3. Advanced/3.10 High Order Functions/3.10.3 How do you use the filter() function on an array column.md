### 3.10.3 How do you use the filter() function on an array column

The `filter()` higher-order function returns a new array containing only the elements that satisfy a given predicate. It operates on an array column and takes a lambda expression that evaluates to a boolean. Unlike the DataFrame `filter()` or `where()` method, which filters rows, this `filter()` filters elements inside an array. It is a native Spark SQL function, so it benefits from Catalyst optimization and whole-stage code generation. It does not explode the array into rows and does not use Python UDF serialization.

**Basic syntax**

PySpark:
```python
from pyspark.sql.functions import filter, col

df.select(filter(col("array_col"), lambda x: <boolean_expression>).alias("new_array"))
```

SQL:
```sql
SELECT filter(array_col, x -> <boolean_expression>) AS new_array FROM table;
```

The lambda takes one argument, the element. Unlike `transform()`, `filter()` does not accept an index argument.

**Example 1: Keep even numbers**

```python
from pyspark.sql.functions import filter, col

df = spark.createDataFrame([(1, [1, 2, 3, 4]), (2, [5, 6, 7, 8])], ["id", "numbers"])
df.select("id", filter(col("numbers"), lambda x: x % 2 == 0).alias("evens")).show()
```

Output:
```
+---+------+
| id| evens|
+---+------+
|  1|[2, 4]|
|  2|[6, 8]|
+---+------+
```

**Example 2: Keep strings longer than a certain length**

```python
from pyspark.sql.functions import filter, col, length

df_str = spark.createDataFrame([(1, ["apple", "fig", "banana"]), (2, ["kiwi", "date"])], ["id", "fruits"])
df_str.select("id", filter(col("fruits"), lambda x: length(x) > 4).alias("long_fruits")).show()
```

Output:
```
+---+----------------+
| id|     long_fruits|
+---+----------------+
|  1| [apple, banana]|
|  2|         [kiwi] |
+---+----------------+
```

**Example 3: Filter out null elements**

If the array contains null elements, you can exclude them with a null check.

```python
from pyspark.sql.functions import filter, col

df_null = spark.createDataFrame([(1, [1, None, 3, None, 5])], ["id", "numbers"])
df_null.select("id", filter(col("numbers"), lambda x: x.isNotNull()).alias("non_null")).show()
```

Output:
```
+---+---------+
| id| non_null|
+---+---------+
|  1|[1, 3, 5]|
+---+---------+
```

**Example 4: Filter an array of structs**

You can filter an array of structs by referencing fields inside the lambda.

```python
from pyspark.sql.functions import filter, col

df_struct = spark.createDataFrame([
    (1, [{"name": "a", "price": 5}, {"name": "b", "price": 15}, {"name": "c", "price": 25}])
], ["id", "items"])

df_struct.select(
    "id",
    filter(col("items"), lambda x: x["price"] > 10).alias("expensive_items")
).show()
```

Output:
```
+---+--------------------+
| id|    expensive_items |
+---+--------------------+
|  1|[{b, 15}, {c, 25}]  |
+---+--------------------+
```

**Example 5: Combine filter with transform**

You can chain higher-order functions. For example, filter even numbers and then double them.

```python
from pyspark.sql.functions import filter, transform, col

df.select(
    "id",
    transform(filter(col("numbers"), lambda x: x % 2 == 0), lambda x: x * 2).alias("doubled_evens")
).show()
```

Output:
```
+---+-------------+
| id|doubled_evens|
+---+-------------+
|  1|       [4, 8]|
|  2|      [12, 16]|
+---+-------------+
```

**SQL syntax**

In SQL, use the arrow syntax `x -> ...`.

```sql
SELECT id, filter(numbers, x -> x % 2 = 0) AS evens FROM my_table;
SELECT id, filter(fruits, x -> length(x) > 4) AS long_fruits FROM my_table;
SELECT id, filter(numbers, x -> x IS NOT NULL) AS non_null FROM my_table;
```

**Null handling**

If the array itself is null, the result is null. If an element is null, the lambda receives null. Whether that null is retained depends on the predicate. For example, `x -> x > 2` will evaluate to null for a null element, and null is treated as false in filter, so the null element is removed. If you want to keep nulls, use `x -> x IS NULL OR x > 2`. In PySpark, use `x.isNull() | (x > 2)`.

**Difference from DataFrame filter**

The DataFrame `filter()` or `where()` method filters rows based on a condition. The higher-order `filter()` function filters elements inside an array column. They are different operations.

```python
# Row-level filter
df.filter(col("id") > 1).show()

# Array-level filter
df.select(filter(col("numbers"), lambda x: x > 1).alias("filtered")).show()
```

**Performance note**

`filter()` is a native Spark SQL function. It is optimized by Catalyst and Tungsten. It avoids the overhead of exploding the array into rows, applying a row filter, and grouping back with `collect_list`. It also avoids Python UDF serialization. For these reasons, it is the preferred way to filter elements inside an array.

**Limitations**

- The input must be an array column.
- The lambda must return a boolean expression.
- The lambda takes only one argument. There is no index parameter.
- Very large arrays can cause memory pressure because the entire array is held in memory.
- Null arrays produce null output. Null elements must be handled explicitly if you want to keep or remove them.

**Summary**

Use `filter()` on an array column to keep only the elements that satisfy a predicate. In PySpark, use `filter(col("array_col"), lambda x: condition)`. In SQL, use `filter(array_col, x -> condition)`. It returns a new array of the same or smaller length. It is native, fast, and avoids UDFs and explode operations. Handle nulls explicitly. Use it together with `transform()` and other higher-order functions for complex array processing.
