# 3.10.2 How do you use the transform() function to modify elements in an array column?

The `transform()` function applies a lambda expression to each element of an array column and returns a new array of the same length. It is a higher-order function in Spark SQL that operates natively on arrays without exploding them into rows or using Python UDFs. You can use it in the DataFrame API with `pyspark.sql.functions.transform` or in SQL with the `transform` function and arrow syntax.

**Basic syntax**

PySpark:
```python
from pyspark.sql.functions import transform, col

df.select(transform(col("array_col"), lambda x: <expression>).alias("new_array"))
```

SQL:
```sql
SELECT transform(array_col, x -> <expression>) AS new_array FROM table;
```

The lambda can take one argument (the element) or two arguments (the element and its zero-based index).

**Example 1: Multiply each element by 2**

```python
from pyspark.sql.functions import transform, col

df = spark.createDataFrame([(1, [1, 2, 3]), (2, [4, 5, 6])], ["id", "numbers"])
df.select("id", transform(col("numbers"), lambda x: x * 2).alias("doubled")).show()
```

Output:
```
+---+---------+
| id|  doubled|
+---+---------+
|  1|[2, 4, 6]|
|  2|[8,10,12]|
+---+---------+
```

**Example 2: Use the index in the transformation**

The lambda can accept a second argument for the index. This is useful when the transformation depends on the position.

```python
df.select("id", transform(col("numbers"), lambda x, i: x + i).alias("indexed")).show()
```

Output:
```
+---+---------+
| id|  indexed|
+---+---------+
|  1|[1, 3, 5]|
|  2|[4, 6, 8]|
+---+---------+
```

**Example 3: Apply conditional logic**

You can use conditional expressions inside the lambda.

```python
from pyspark.sql.functions import when

df.select(
    "id",
    transform(col("numbers"), lambda x: when(x > 2, x * 10).otherwise(x)).alias("conditional")
).show()
```

Output:
```
+---+------------+
| id| conditional|
+---+------------+
|  1| [1, 2, 30]|
|  2|[40, 50, 60]|
+---+------------+
```

**Example 4: Transform string arrays**

`transform` works on arrays of any type, including strings.

```python
df_str = spark.createDataFrame([(1, ["apple", "banana"]), (2, ["cherry", "date"])], ["id", "fruits"])
df_str.select("id", transform(col("fruits"), lambda x: upper(x)).alias("upper_fruits")).show()
```

Output:
```
+---+----------------+
| id|    upper_fruits|
+---+----------------+
|  1| [APPLE, BANANA]|
|  2| [CHERRY, DATE] |
+---+----------------+
```

**Example 5: Handle nulls**

If the array is null, the result is null. If an element is null, the lambda receives null and must handle it. Use `coalesce` or a null check inside the lambda.

```python
from pyspark.sql.functions import coalesce, lit

df_null = spark.createDataFrame([(1, [1, None, 3])], ["id", "numbers"])
df_null.select(
    "id",
    transform(col("numbers"), lambda x: coalesce(x, lit(0)) * 2).alias("doubled")
).show()
```

Output:
```
+---+---------+
| id|  doubled|
+---+---------+
|  1|[2, 0, 6]|
+---+---------+
```

**Example 6: Nested transform**

You can nest `transform` calls for arrays of arrays.

```python
df_nested = spark.createDataFrame([(1, [[1, 2], [3, 4]])], ["id", "matrix"])
df_nested.select(
    "id",
    transform(col("matrix"), lambda row: transform(row, lambda x: x * 2)).alias("doubled_matrix")
).show()
```

Output:
```
+---+----------------+
| id| doubled_matrix |
+---+----------------+
|  1|[[2, 4], [6, 8]]|
+---+----------------+
```

**SQL syntax**

In SQL, use the arrow syntax `x -> ...` or `(x, i) -> ...`.

```sql
SELECT id, transform(numbers, x -> x * 2) AS doubled FROM my_table;
SELECT id, transform(numbers, (x, i) -> x + i) AS indexed FROM my_table;
```

**Performance note**

`transform` is a native Spark SQL function. It benefits from the Catalyst optimizer and whole-stage code generation. It does not cross the JVM-Python boundary like a Python UDF, and it does not cause a shuffle like exploding the array. It is the preferred way to modify array elements.

**Limitations**

- The input must be an array column.
- The lambda must return a value of a type that Spark can infer.
- Very large arrays can cause memory pressure because the entire array is held in memory.
- Null arrays produce null output. Null elements must be handled inside the lambda.

**Summary**

Use `transform()` to apply a lambda to each element of an array column. It returns a new array of the same length. You can use the element alone or the element and its index. It supports conditional logic, string operations, and nesting. In PySpark, use `transform(col("array_col"), lambda x: ...)`. In SQL, use `transform(array_col, x -> ...)`. It is fast, native, and avoids the overhead of UDFs or explode operations.
